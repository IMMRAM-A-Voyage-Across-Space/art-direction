# Shipped Sprites

Every sprite that has actually shipped to `png/` — **128 PNGs**, grouped by
folder. This page is generated from what's on disk, not from a spec, so it cannot
drift the way a hand-maintained inventory can: if a file lands in
`assets/overworld/png/` or `assets/ui/png/`, it belongs here.

!!! info "Geometry"
    Overworld tiles are a 64×64 canvas drawn as a 2:1 isometric diamond
    (64 wide × 32 tall). See the [tile spec](reference/tile-spec.md).
